# AGENTES - ᴘᴛ

Este documento define as regras que agentes de IA devem seguir ao trabalhar neste repositório. O objetivo é manter consistência, qualidade, segurança e escalabilidade em toda a aplicação.

## Sobre o projeto

O Lamborghini é um projeto de estudos inspirado no ecossistema digital da fabricante automotiva de luxo Lamborghini.

O repositório utiliza uma arquitetura monorepo para integrar uma aplicação web e um aplicativo mobile, compartilhando recursos, regras de negócio e integrações sempre que apropriado.

A plataforma busca reproduzir e expandir a experiência digital de uma fabricante automotiva de luxo, contemplando showroom digital, personalização de veículos, pedidos, gerenciamento de clientes, garagem digital, monitoramento, rastreamento, manutenção, concessionárias e eventos.

O projeto possui finalidade educacional e não representa uma aplicação oficial, produto comercial ou serviço autorizado pela Lamborghini.
