A study project inspired by Lamborghini’s digital ecosystem, developed using a monorepo architecture that encompasses both a web application and a mobile app.

## About the Project

The project consists of a web application and a mobile app that simulate the digital experience of a luxury automotive manufacturer, allowing users to explore vehicles, customize them, make purchases, and manage their relationship with the brand.

The goal is to replicate and expand upon the digital experience of a luxury automotive manufacturer by integrating vehicle showcases, customization, sales, and customer relationship management into a single platform.

## Features

### Website
**Digital Showroom:** Pages showcasing vehicle models, including technical specifications, images, and detailed information.
**Vehicle Customization:** An interactive configurator for personalizing models—selecting body colors, wheels, seats, interior finishes, and other components—with real-time visualization of changes.
**Custom Orders:** The ability to configure a vehicle according to personal preferences and submit an order request.
**Customer Area:** Authentication and access to exclusive platform features.
**Vehicle Management:** Access to information, history, mileage, and data for registered vehicles.
**Dealership Locator:** Finding nearby dealerships.
**Service Scheduling:** Booking appointments for inspections and maintenance.

### Mobile App
**Authentication:** Login and customer account management.
**Digital Garage:** Tracking vehicles linked to the user's account.
**Monitoring:** Accessing vehicle information and mileage.
**Tracking:** Locating the user's vehicle.
**Maintenance:** Scheduling and tracking inspections and services.
**Notifications:** Reminders for inspections, maintenance, and other appointments.
**Dealerships:** Locating nearby dealership locations.
**Events:** Information regarding brand events, experiences, and activities.

## Learning objectives

- Develop integrated web and mobile applications.
- Work with a monorepo architecture.
- Implement authentication and user management.
- Develop interactive and responsive interfaces.
- Create real-time product customization experiences.
- Work with geolocation and tracking.
- Implement notifications and scheduling systems.
- Develop integrations between different platforms.
