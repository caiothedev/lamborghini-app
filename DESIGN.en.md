# VISUAL GUIDE - ᴇɴ

This document outlines the project’s visual standards, including colors, typography, spacing, and other design elements. It serves as a reference to ensure consistency across all designed interfaces and user experiences.

## Key features:
- Surfaces primarily in pure black or a soft background tone, with white and gold as the only accent colors.
- All-caps display typography at extreme scales (120px, 80px, 54px) with reduced line spacing.
- Full-screen video hero section, featuring cinematic content of events/vehicles.

## What not to do!

Here is a list of practices to avoid adding to the code at all costs; they go against the project's standards:

- Emojis (Always prefer SVG icons)
- Text containing "—" (em dashes) or ";" (semicolon)
- Variables, elements, or the code itself in Portuguese
- Comments in English and test descriptions in Portuguese
- Loading texts with "..."
